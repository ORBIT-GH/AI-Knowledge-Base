# 存储与特征计算说明

本文件补充第一版内部实现。程序按以下顺序运行。

## 1. 初始化数据库

`Database.initialize()` 创建以下表：

- `market_bars`：行情、持仓、成交和结算数据。
- `manual_metrics`：用户每天提交的现货、库存、开工率等数据。
- `research_notes`：新闻、公告和研究材料。
- `crawler_runs`：爬虫运行状态和导入数量。

## 2. 写入数据

所有写入均通过唯一键执行 upsert。相同交易日、品种、合约和来源重复提交时更新原记录，不添加重复行。

## 3. 计算日报数据包

`build_daily_report_context()` 依次执行：

1. 读取最近 20 个交易日行情。
2. 计算 1 日、5 日涨跌、MA5、MA20、持仓变化和成交量 Z-Score。
3. 读取最新手工指标。
4. 计算库存变化和现货基差。
5. 根据阈值生成异常标记。
6. 读取最近 7 天、最多 3 条相关资讯。
7. 截断资讯摘要。
8. 计算混合中英文 token 估算值。

## 4. 返回边界

返回内容不包含：

- 完整 K 线历史。
- 向量。
- 爬虫 HTML 或原始 JSON。
- 新闻全文。
- 数据库内部行 ID。

这些数据继续留在 SQLite 中，只有聚合字段进入 OpenClaw。
