# 第一版架构说明

## 目标

OpenClaw 每天生成烧碱、PVC、焦煤期货报告时，只接收已经清洗和计算过的精简数据包。爬虫原始输出、历史行情、新闻全文和完整报告不进入 OpenClaw 上下文。

## 组件

```text
爬虫 / 手工数据 / 资讯
          |
          v
       FastAPI 服务
          |
          v
       SQLite 数据库
          |
          v
        特征计算
          |
          v
  daily_report_context
          |
          v
      MCP stdio 服务
          |
          v
        OpenClaw
          |
          v
        每日报告
```

## 边界

- SQLite 是持久数据源，不进入模型上下文。
- FastAPI 负责数据导入、查询和爬虫调度。
- 特征计算使用确定性代码，模型不负责算指标。
- MCP 只返回短字段、摘要和引用。
- OpenClaw 负责解释数据和撰写报告。
- 每份报告使用独立会话，旧报告通过摘要续接。

## 数据分层

| 层 | 内容 | 是否进入 OpenClaw |
|---|---|---|
| 原始层 | 爬虫 HTML、JSON、原始文件 | 否 |
| 标准层 | 行情 K 线、手工指标、资讯 | 否 |
| 特征层 | 均线、涨跌、持仓变化、基差、异常 | 只进入精简结果 |
| 报告层 | 日报数据包、引用、数据质量 | 是 |
| 会话层 | 当日报告、最近对话 | 是，报告后归档 |
